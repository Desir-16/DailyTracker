# Daily Tracker Support

For installation help, bug reports, privacy questions, or licensing enquiries,
open an issue in the official repository:

**https://github.com/Desir-16/DailyTracker/issues**

When reporting a problem, include:

- Daily Tracker version
- Android version and phone model
- A short description of what happened
- A screenshot when it does not contain private information

Do not post passwords, email addresses, Google Drive credentials, production
signing files, private photos, or private backup files in a public issue.
